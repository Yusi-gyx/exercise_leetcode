## 📌 仓库简介

建立这个仓库初衷是为了沉淀数据结构与算法的核心知识，培养良好的编码习惯。
* **语言选择**：主要使用 **C++**（专注于高效的内存管理与底层性能调优），部分题目配合 **Python** 进行快速原型验证。
* **解题标准**：不仅追求 `Accept`，更追求优化的时间/空间复杂度，力求包含**多种解法**（如暴力、递推、动态规划、双指针等）与思路对比。
